# Changelog

## 1.0.0
- First clean release for GitHub (github.com/asmpro7/provenance).
- Plagiarism check of a paper or draft file (txt/md/tex/docx) against the
  PDFs in your library, with copied and lightly reworded passages and
  their citation status in a single-file HTML report (filter, sort, CSV,
  print to PDF).
- Reference fetching into a collection via Semantic Scholar, alone or
  combined with a check, plus whole-collection checks.
- Standalone PDFs (no parent item) work as the checked paper and as
  sources.
- Settings pane with strict/normal/lenient presets, per-setting controls
  and a fingerprint index for fast repeat checks. Preset bug fixed: Strict
  used to stop applying partway (a float threshold hit an int-locked pref)
  and never confirmed.
- Author: Ahmed Abdelmageed (https://orcid.org/0009-0002-7902-690X). The
  report footer links his name to the ORCID profile.
- Everything runs locally; Semantic Scholar is contacted only by the
  reference-fetch commands.
- Report footer shows just the plugin name: "Generated by Provenance -
  Ahmed Abdelmageed (linked to ORCID) - github.com/asmpro7/provenance".
  The in-Zotero summary note drops the version too.
- Progress dialog title reads "Fetch and Check" (no "&&" anywhere in the
  interface).
- Reference fetching: the garbled-title cleanup search to Semantic
  Scholar used a 15s timeout, too short for a cold query, so the first
  attempt always timed out and only the retry worked. Timeout is now 30s.
